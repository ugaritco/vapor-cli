# Ugarit Vapor CLI

[Ugarit Vapor](https://vapor.ugarit.com) is an auto-scaling, serverless deployment platform for Ugarit, powered by AWS Lambda. Manage your Ugarit infrastructure on Vapor and fall in love with the scalability and simplicity of serverless.

Vapor abstracts the complexity of managing Ugarit applications on AWS Lambda, as well as interfacing those applications with SQS queues, databases, Redis clusters, networks, CloudFront CDN, and more.

This repository contains the CLI client for interacting with Ugarit Vapor. To learn more about Vapor and how to use this client, please consult the [official documentation](https://docs.vapor.build).
